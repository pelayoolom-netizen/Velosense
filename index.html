VeloSense

Ciclocomputador GPS con Coach Inteligente & Strava

⚡ ¡Tu APK Nativa ya está compilada y lista!

Este proyecto es una aplicación nativa de Android desarrollada en Kotlin & Jetpack Compose. Si descargaste el proyecto como ZIP o usas un conversor web (Web2APK, Cordova, etc.), a continuación tienes las formas directas de instalar el APK.

📦

¿Cómo obtener e instalar el archivo APK?

1
Descarga directa desde Google AI Studio
En la esquina superior derecha de AI Studio, haz clic en el menú de Configuración / Exportar y selecciona "Generate APK / Download APK". Te descargará el instalador directamente en tu teléfono u ordenador sin necesidad de convertir nada.
2
Ubicación del APK ya compilado en el ZIP
Si descomprimes el archivo ZIP en tu ordenador, el archivo .apk ya se encuentra generado en las siguientes rutas:
app/build/outputs/apk/debug/app-debug.apk
.build-outputs/app-debug.apk
¡Simplemente copia ese archivo app-debug.apk a tu móvil Android e instálalo!
3
Compilar con Android Studio o Terminal
Puedes abrir esta carpeta en Android Studio y pulsar en Build > Build Bundle(s) / APK(s) > Build APK(s), o ejecutar desde la consola:
./gradlew assembleDebug
4
Uso con Conversores Web-to-APK (Website 2 APK, AppsGeyser, etc.)
Si estás subiendo el ZIP a una plataforma de conversión que exige un index.html, este archivo cumple con todos los requisitos necesarios para empaquetar la aplicación en un WebView con pantalla completa y soporte táctil.
